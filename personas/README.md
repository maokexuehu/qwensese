# 角色卡格式与编写指南（personas/）

本目录存放**角色卡**（persona card）：一个 `.md` 文件定义一个虚拟角色或一套「系统」角色。
服务启动时扫描 `personas/*.md`，除 `README.md` 与 `template.md` 外都作为可切换的角色卡，
在页面左侧列表展示。

| 文件 | 用途 |
| --- | --- |
| `persona.md` | 默认示例角色（林晚，旧书店店主） |
| `example-mentor.md` | 第二个示例角色（周屿，温柔学姐） |
| `template.md` | 空白模板，复制出来改成自己的角色 |
| `README.md` | 本说明，不作为角色卡加载 |

新增角色：复制 `template.md` 为 `personas/<角色名>.md`，填字段，然后刷新页面即可；
用可视化页面编辑字段时会原子写回对应 `.md` 文件，**不需要重建模型**。

---

## 1. 文件格式

每个字段以 `## 字段名` 开头，字段内容写在下一行起，可多行：

```markdown
## 名字
林晚

## 年龄
29

## 开场白
晚上九点四十，店里的灯已经关了一半……
```

解析规则：

- 字段名必须与下表完全一致（区分文字，不区分行尾空白）；
- 未提供的字段按空处理，不会报错；
- 文件编码必须是 UTF-8（推荐不带 BOM）；
- 文件名只允许 `[A-Za-z0-9_\-\u4e00-\u9fa5]`，服务端会做路径穿越校验。

---

## 2. 字段说明（13 个）

| 字段 | 作用 | 编写建议 |
| --- | --- | --- |
| `名字` | 角色名 | 用于开场白与摘要展示 |
| `年龄` | 数字 | 虚拟角色，必须 ≥ 18 |
| `身份` | 职业 / 处境 | 决定角色的生活细节与用词 |
| `与用户的关系` | 认识多久、什么关系 | 越具体，第一轮对话越自然 |
| `前情提要` | 本轮对话开始前的背景 | 可留空；只写「截至现在」的事实 |
| `外貌` | 具体特征 | 写疤、旧衣物、气味等具体物件，避免空泛形容词 |
| `性格` | 行为倾向 | 写「什么情况下会怎么做」，而不是性格标签 |
| `说话风格` | 称呼、句长、口头禅 | 对「像不像」影响最大的一项 |
| `行为准则` | 底线、拒绝方式 | 防止角色变成无原则的顺从者 |
| `尺度` | 0 / 1 / 2 / 3 | 控制描写强度的单一开关，见第 3 节 |
| `禁忌` | 不希望的走向 | 用否定句写「不要变成什么样」 |
| `开场白` | 第一幕场景 + 第一句话 | 三句以内，留有可接的钩子 |
| `示例对话` | 1～2 轮示例 | 最有约束力的一项，优先级高于抽象规则 |

「我的角色卡」（玩家自己）使用另一套 11 字段格式，见 `config/user_personas/default.md`
与页面右侧「我的角色卡」面板，格式同样是 `## 字段名`。

---

## 3. 尺度档位（`尺度` 字段）

| 值 | 含义 |
| --- | --- |
| 0 | 纯剧情向，身体接触止于牵手、拥抱 |
| 1 | 暧昧张力：目光、距离、呼吸、布料摩擦 |
| 2 | 成人向：可写身体与感官，节奏放慢，重氛围与反应 |
| 3 | 直白描写：不回避器官与行为 |

导入模型脚本会把该数值翻译成明确指令写入 SYSTEM，模型无需猜测。
本功能仅面向**成年、虚构**角色，使用者需自行确保内容合法合规（见根目录 `SECURITY.md`
与 README 的免责声明）。

---

## 4. 角色卡中不应出现的内容

一张角色卡只描述**一个角色（或一套系统）本身**：

| 不要写 | 原因 |
| --- | --- |
| 未来剧情走向、伏笔、后续安排 | 应由对话自然产生，写进卡里会变成剧透与硬性剧本 |
| NPC 名单、配角表、势力成员表 | 固定名单会导致模型反复拉同一批人出场 |
| 阶段表、场景库、世界观清单 | 属于卡外内容，塞进卡里只消耗上下文 |
| 多个角色的合订本 | 一张卡只演一个角色，切换角色应切换卡片 |

「系统」类卡片同理：只写该系统自身的规则、语气与数值，不在卡内固定 NPC。

从对话导入生成的卡片也遵循此规则：导入器会要求模型只输出角色人设，
并自动剪除误加的 `【NPC 池】`、`【场景库】` 等段落，在结果提示中说明剪除行数。

---

## 5. 修改生效方式

| 修改方式 | 是否生效 | 是否需要重建模型 |
| --- | --- | --- |
| 页面内编辑字段并保存 | 立即生效（每次请求现场拼 SYSTEM） | 否 |
| 直接改 `.md` 文件 + 刷新页面 | 立即生效 | 否 |
| 用 `scripts/import-model.ps1` 打包模型 | 影响 Ollama 侧的 SYSTEM 模板 | 是（该脚本即重建流程） |

临时试演也可以直接在对话中说明「现在扮演……」，但效果弱于角色卡。

---

## 6. 多角色并行

```powershell
# 复制当前角色卡作为新角色
Copy-Item personas/persona.md personas/persona-linwan.md

# 使用示例角色作为默认卡
Copy-Item personas/example-mentor.md personas/persona.md

# 为不同角色分别打包 Ollama 模型（可选）
scripts/import-model.ps1 -Name linwan
```

页面上切换角色卡不会清空历史对话；需要干净开局时点「改开场白 / 从这句开始」。
